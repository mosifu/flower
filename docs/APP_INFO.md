# 小程序注册信息（可复制到公众平台）

以下内容用于微信公众平台的「基本信息」填写，可直接复制粘贴。

## 基础信息

| 字段 | 内容 |
|---|---|
| 小程序名称 | 随心一拍-花知道（若平台不接受「-」，改为：随心一拍花知道 或 随心一拍·花知道） |
| 小程序简称 | 花知道（若平台提示与名称重复，可填：随心一拍） |
| 小程序介绍 | 随心一拍，识花科普小助手。路边随手拍一朵花，AI 快速识别花名，查看科属、花期、花语等科普知识，收藏花卡、收集图鉴、解锁成就。 |
| 服务类目建议 | 工具-图片 / 摄影（以公众平台实际可选类目为准，个人主体可选范围有限） |
| 开发模式 | 小程序云开发（无需自建服务器与域名备案服务器） |

> 介绍约 60 字，符合「120 字以内」的填写要求。

## 头像（Logo）要求

- 正方形 1:1 图片，建议 200×200 像素以上（公众平台会自动缩放）。
- 格式 PNG / JPG，文件大小不超过 2M（以公众平台提示为准）。
- AI 版头像（已定稿，推荐）：`miniprogram/images/avatar-ai-v2.png`（1024×1024，Seedream 5.0 Lite 生成，向日葵配色版）。
- 矢量设计稿：`miniprogram/images/avatar.png`（512×512 代码绘制版，可裁剪后上传）。

## 备案与上线提醒

- 小程序上线前需完成 ICP 备案（公众平台「小程序备案」入口提交，周期约数天至两周）。
- 提审前需在「设置-服务内容声明-用户隐私保护指引」配置照片、存储等用途说明。

## 文案备用

一句 slogan（可用于分享文案 / 首页副标题）：

> 随心一拍，路边的花一拍就知道。
